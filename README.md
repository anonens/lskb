# JUZ40 · Мат-Гео кері байланыс сайты

Математика және геометрия мұғалімдеріне LIVE сабақ бойынша апталық кері байланыс беретін сайт.
Екі пән, SMART/JUNIOR желілері, айлар мен апталар, әр мұғалім-потоктың ұнату және қатысым пайыздары, пікірлер және «Таныстым» батырмасы бар.
Бұл нұсқа Vercel-де өз мекенжайымен жұмыс істейді және әкімші бөліміне құпиясөзбен кіреді.

- **Сайт:** `https://keribailanys.vercel.app`
- **Әкімші бөлімі:** `https://keribailanys.vercel.app/admin` — әкімші құпиясөзімен кіреді. Құпиясөздің өзі браузерге берілмейді.
- Сайтқа келушілер тек «Сайтта» деп қосылған апталарды көреді. Жоба күйіндегі апталар серверден шықпайды.

## Vercel-ге шығару (бір рет, шамамен 10 минут)

**1. Кодты GitHub-қа салыңыз**
github.com → **New repository** → атын жазыңыз (мысалы `juz40-matgeo`) → **Private** → Create.
Ашылған беттен **uploading an existing file** сілтемесін басып, осы қалтадағы барлық файл мен қалталарды сүйреп салыңыз → **Commit changes**.

**2. Vercel-де жоба ашыңыз**
vercel.com → **Add New… → Project** → GitHub репозиторийін таңдап **Import** басыңыз.
Framework Preset: **Other** (баптаулар `vercel.json` ішінде тұр, басқа ештеңені өзгертпеңіз) → **Deploy**.

**3. Деректер қоймасын қосыңыз (Vercel Blob)**
Жобаның ішінде: **Storage → Create → Blob** → Access: **Private** → Create.
Жасалған дүкенді осы жобаға **Connect** етіңіз (Production және Preview). Vercel қажетті айнымалыларды өзі қосады.
«Custom Environment Variable Prefix» өрісін өзгертсеңіз де (мысалы `keribailanys`), сайт оны өзі табады.

**4. Қайта жариялаңыз**
**Deployments** → соңғы деплойдың **⋯** мәзірі → **Redeploy**. Сонда Blob іске қосылады.

**5. Тексеріңіз**
Сайтты ашыңыз → `/admin` → құпиясөзбен кіріңіз → «Мәтіндер» бөлімінде бір сөзді өзгертіп, **Сақтау және жариялау** басыңыз → бетті жаңартыңыз. Өзгеріс сақталып тұрса, бәрі дұрыс.
Әкімшіге кіру үшін де Blob керек: кірудің қауіпсіз кілті сонда сақталады.

> Өз доменіңізді қосу: **Settings → Domains**.

## Апта сайын: SapaLine-нан сандарды алу (шамамен 1 минут)

**Бір рет баптау (жаңартудан кейін бұрынғы бетбелгіні ауыстырыңыз).** `/admin` → «Нәтижелер» → **SapaLine-нан импорттау**. Терезедегі **JUZ40 · SapaLine** батырмасын браузердің бетбелгілер жолағына сүйреп апарыңыз
(жолақ көрінбесе: Chrome-да ⌘⇧B / Ctrl+Shift+B). Сүйреу болмаса, **Кодты көшіру** басып, жаңа бетбелгі жасап, мекенжай өрісіне қойыңыз.

**Әр апта:**
1. SapaLine → **Live Sabaq → SMART немесе JUNIOR → Математика** → керек аптаны таңдаңыз.
2. Бетбелгідегі **JUZ40 · SapaLine** батырмасын басыңыз. Оң жақ жоғарыда таңдалған аптадағы көрінетін сабақтар бір-бірлеп оқылады. Кестеде іздеу/сүзгі болса, толық апта үшін оны тазалаңыз. Оқу кезінде аптаны ауыстырмаңыз. Біткен соң **Көшіру** басыңыз.
3. `/admin` → **SapaLine-нан импорттау** → өріске қойыңыз → **Импорттау**. Шыққан есепті қарап, **Сақтау және жариялау** басыңыз.
4. Геометрия үшін 1–3 қадамды қайталаңыз.

**«Көшіру» жұмыс істемесе:** бетбелгі терезесіндегі **«Мәтінді белгілеу»** → ⌘C / Ctrl+C → сайттағы импорт өрісіне ⌘V / Ctrl+V. Немесе **«JSON жүктеу»** → `/admin` → «SapaLine-нан импорттау» → **«JSON файлды ашу»** → «Импорттау». Файлды ашу тек импорт өрісін толтырады; нәтижелер «Импорттау» және «Сақтау және жариялау» арқылы сақталады. Автоматты көшіру сәтсіз болса, терезеде нақты хабар көрсетіледі.

Бетбелгі SapaLine-да ештеңе өзгертпейді. Әр сабақтың «Ұнау %» терезесін ашып, **Ұнады / Орташа / Ұнамады** сандарын оқиды да, терезені жабады.
Ұнату пайызы мұғалім-поток бойынша апта ішіндегі сауалнамасы бар сабақтардан есептеледі: Ұнады ÷ (Ұнады + Орташа + Ұнамады) × 100. «Опрос өтті» қатысымның бөлімі ретінде қолданылмайды.
Сауалнамасы жоқ сабақтар және қатысым дерегі жоқ сабақтар есепте бөлек көрсетіледі. Сауалнамасыз сабақта қатысым бар болса, ол да импортталады. Жазылған пікірлер қайта импортталғанда сақталып қалады.

### Қатысым пайызы қалай есептеледі

- Әр мұғалім-потоктың карточкасында және мұғалімдер тізімінде **Қатысым %** шығады.
- Сабақтардың «Қатысты» және «Жалпы» сандары бар болса: **Σ Қатысты ÷ Σ Жалпы × 100**. Мысалы, 80/100 және 10/20 → 90/120 = **75%**. Бір оқушы бірнеше сабаққа қатысса, әр сабақ бөлек қатысым болып есептеледі; бұл бірегей оқушылар саны емес.
- Кейбір сабақта тек «Қатысым %» бар болса, қолжетімді сабақ пайыздарының орташа мәні алынады. Карточкада **«Сабақ пайыздарының орташа мәні»** деп белгіленеді.
- Қатысым дерегі жоқ сабақтар бөлімге қосылмайды. **0%** — жарамды нәтиже; дерек жоқ болса **«— / Дерек әлі енгізілмеген»** көрсетіледі.
- `/admin` → «Нәтижелер»: «Қатысты / Жалпы» сандарын немесе қатысым пайызын қолмен енгізуге болады. Сандар бар кезде пайыз автоматты есептеледі.
- Бұрын сақталған апталардың қатысымы өздігінен пайда болмайды: сол апталарды жаңартылған бетбелгімен қайта импорттаңыз.

### Қайта импорт және қате экспорт

Импорт мұғалімнің толық атымен, Sapaline атымен және алғашқы екі сөздің кері ретімен сәйкестендіреді. SMART/JUNIOR және екі пәннің нәтижелері бөлек сақталады. Бір аптаны қайта импорттау жаңа сандармен алмастырады, үстінен қоспайды; пікірлер сақталады. Бір экспорттағы бірдей сабақ нөмірі (немесе күні/уақыты/мұғалімі/ағымы) екі рет есептелмейді; екі түрлі мәнді қайталанған сабақ қабылданбайды.

Оқылмай қалған сауалнама, теріс/қате сандар, мұғалімі немесе ағымы жоқ жол, бос экспорт қабылданбайды. Қате кезінде әкімші жобасы өзгермейді. Экспортта мүлдем жоқ мұғалім-потоктың бұрынғы нәтижесі сақталады, есепте ескертіледі. Жаңа экспортта ұнату не қатысымның біреуі жоқ болса, сол көрсеткіштің бұрынғы мәні сақталады.

**Нұрдәулет ағай:** «Қуаныш» — фамилиясы, толық аты **Қуаныш Нұрдәулет**, сайттағы аты **Нұрдәулет ағай**. Бастапқы және бұрыннан Blob-та сақталған деректер оқылғанда түзетіледі; мұғалімнің идентификаторы, фотосы, нәтижелері сақталады.

Бетбелгінің JSON пішімі (`v: 2`; ескі ұнату экспорты да қабылданады):

```json
{
  "source": "sapaline",
  "v": 2,
  "subject": "geometry",
  "line": "smart",
  "period": "4-АЙ 1-АПТА",
  "rows": [{
    "num": "1",
    "date": "12.10.2026",
    "time": "10:00",
    "teacher": "Қуаныш Нұрдәулет",
    "agym": "ГЕОМ-21",
    "att": "80%",
    "survey": {"liked": 80, "avg": 15, "disliked": 5, "present": 80, "total": 100}
  }]
}
```

Апталық `juzAuto` интеграциясында жолдар объект ретінде немесе `[date, time, teacher, agym, liked, avg, disliked, present, total, att]` массиві ретінде беріледі. Бұрынғы жеті элементтік массивтер де жұмыс істейді. `expect` ұнату сандары мен сауалнамалы сабақтардың қосындысын тексереді.

**Тексеру:** `npm test` импортты, пайыздарды, қайта импортты, атының түзетілуін, HTML көрсетілімін және API-де сақтау/оқуды тексереді. Sapaline-ның нақты аккаунтындағы апта бұл өзгерісті әзірлеу кезінде тексерілмеді: кіру қажет болды. Бетбелгі қазіргі кодта сипатталған кесте/карточка және сауалнама құрылымына сүйенеді.

## Ай ауысқанда

Мұғалімдердің пәні мен потогы ай сайын өзгеруі мүмкін:
- «Айлар мен апталар» → **+ Ай қосу**. Өткен айдағы «кім қайда береді» тізімі көшіріледі. Өзгергенін «Кім қайда береді» бөлімінде түзетесіз.
- Немесе жаңа айдың бірінші аптасын бірден импорттаңыз. Ай мен апта өзі жасалады, жаңа мұғалім мен поток та қосылады.
  Жаңа мұғалімнің атын («Дәулет ағай» сияқты) және фотосын «Мұғалімдер» бөлімінде тексеріңіз.

Өткен айлардың нәтижелері өзгермейді.

## Пайдалы мәліметтер

- **Құпиясөзді ауыстыру:** **Settings → Environment Variables** → Key: `ADMIN_PASSWORD`, Value: жаңа құпиясөз → **Save** → Redeploy. Сонда тек жаңа құпиясөз жұмыс істейді, бұрын кірген құрылғылардың бәрі шығып қалады. Құпиясөз чатта жазылғандықтан, оны кейін ауыстырып қойған дұрыс.
- **Кіру ұзақтығы:** әкімші бір құрылғыдан кірсе, 30 күн бойы қайта сұралмайды. «Шығу» батырмасы кіруді бірден тоқтатады.
- **Екі адам бір уақытта өзгертсе:** бірінші сақталғаны өтеді. Екіншісіне «Сайттың жаңа нұсқасы бар» деген хабар шығады — жаңа нұсқаны ашып, өзгерісті қайта енгізеді. Деректер ешқашан үнсіз өшпейді.
- **Резерв көшірмелер:** әр сақтаудың көшірмесі Blob дүкеніндегі `data/history/` қалтасында тұрады (соңғы 40). Қате өзгерісті қайтару керек болса, керек көшірме сонда.
- **Іздеу жүйелері:** сайт Google-да көрсетілмейді (`noindex`).
- **Бастапқы деректер:** `seed/data.json` — claude.ai нұсқасындағы деректер (2026 ж. 2 қазан, 3-АЙ 4-АПТА, Junior математикамен). Бірінші сақтаудан кейін деректер Blob-та тұрады.
  claude.ai нұсқасында одан кейін қосылған апталарды мұнда сол аптаны импорттау арқылы қосасыз.

## SapaLine-ды толық автоматты түрде алу туралы

Сайттың өзі SapaLine-ға кіріп, сандарды алуы үшін SapaLine жағынан ресми қол жеткізу керек:
тек оқуға арналған аккаунт және API кілті. Оны SapaLine иесі ғана бере алады. Сондай рұқсат болса, сайтқа бір серверлік функция қосылады.
Әзірге сандар бетбелгі арқылы алынады. Репозиторийдегі `juzAuto` — сыртқы апталық тапсырмаларға арналған импорт интерфейсі; ол өздігінен кесте бойынша Sapaline-ға кіріп, сандарды алмайды.

## Компьютерде іске қосу (міндетті емес)

Node.js 22.x керек (`package.json` және Vercel баптауы).

```bash
npm install
cp .env.example .env.local      # қаласаңыз, басқа ADMIN_PASSWORD жазыңыз
npm run dev                     # http://localhost:3000   әкімші: http://localhost:3000/admin
npm test                        # импорт, көрсетілім және API тексерістері
```

Компьютерде деректер `.data/` қалтасында сақталады.

| `test/` | `npm test` тексерістері |
