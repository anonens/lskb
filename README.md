# JUZ40 · Мат-Гео кері байланыс сайты

Математика және геометрия мұғалімдеріне LIVE сабақ бойынша апталық кері байланыс беретін сайт.
claude.ai-дағы нұсқамен бірдей: екі пән, апталар, әр мұғалімнің ұнату пайызы, «Таныстым» батырмасы.
Бұл нұсқа Vercel-де өз мекенжайымен жұмыс істейді және әкімші бөліміне құпиясөзбен кіреді.

- **Сайт:** `https://<жоба-аты>.vercel.app`
- **Әкімші бөлімі:** `https://<жоба-аты>.vercel.app/admin` — сіз чатта берген құпиясөзді сұрайды. Ол алдын ала бапталған: кодта құпиясөздің өзі жоқ, тек шифрланған хэші тұр.
- Сайтқа келушілер тек «Сайтта» деп қосылған апталарды көреді. Жоба күйіндегі апталар серверден шықпайды.

---

## Vercel-ге шығару (бір рет, шамамен 10 минут)

**1. Кодты GitHub-қа салыңыз**
github.com → **New repository** → атын жазыңыз (мысалы `juz40-matgeo`) → **Private** → Create.
Ашылған беттен **uploading an existing file** сілтемесін басып, осы қалтадағы барлық файл мен қалталарды сүйреп салыңыз → **Commit changes**.

**2. Vercel-де жоба ашыңыз**
vercel.com → **Add New… → Project** → GitHub репозиторийін таңдап **Import** басыңыз.
Framework Preset: **Other** (баптаулар `vercel.json` ішінде тұр, басқа ештеңені өзгертпеңіз) → **Deploy**.

**3. Деректер қоймасын қосыңыз (Vercel Blob)**
Жобаның ішінде: **Storage → Create → Blob** → Access: **Private** → Create.
Жасалған дүкенді осы жобаға **Connect** етіңіз (Production және Preview). Vercel қажетті айнымалыларды өзі қосады.

**4. Қайта жариялаңыз**
**Deployments** → соңғы деплойдың **⋯** мәзірі → **Redeploy**. Сонда Blob іске қосылады.

**5. Тексеріңіз**
Сайтты ашыңыз → `/admin` → құпиясөзбен кіріңіз → «Мәтіндер» бөлімінде бір сөзді өзгертіп, **Сақтау және жариялау** басыңыз → бетті жаңартыңыз. Өзгеріс сақталып тұрса, бәрі дұрыс.
Әкімшіге кіру үшін де Blob керек: кірудің қауіпсіз кілті сонда сақталады.

> Өз доменіңізді қосу: **Settings → Domains**.

## Апта сайын: SapaLine-нан сандарды алу (шамамен 1 минут)

**Бір рет баптау.** `/admin` → «Нәтижелер» → **SapaLine-нан импорттау**. Терезедегі **JUZ40 · SapaLine** батырмасын браузердің бетбелгілер жолағына сүйреп апарыңыз
(жолақ көрінбесе: Chrome-да ⌘⇧B / Ctrl+Shift+B). Сүйреу болмаса, **Кодты көшіру** басып, жаңа бетбелгі жасап, мекенжай өрісіне қойыңыз.

**Әр апта:**
1. SapaLine → **Live Sabaq → Математика** → керек аптаны таңдаңыз.
2. Бетбелгідегі **JUZ40 · SapaLine** батырмасын басыңыз. Оң жақ жоғарыда сабақтар бір-бірлеп оқылады. Біткен соң **Көшіру** басыңыз.
3. `/admin` → **SapaLine-нан импорттау** → өріске қойыңыз → **Импорттау**. Шыққан есепті қарап, **Сақтау және жариялау** басыңыз.
4. Геометрия үшін 1–3 қадамды қайталаңыз.

Бетбелгі SapaLine-да ештеңе өзгертпейді. Әр сабақтың «Ұнау %» терезесін ашып, **Ұнады / Орташа / Ұнамады** сандарын оқиды да, терезені жабады.
Пайыз мұғалім-поток бойынша апта ішіндегі барлық сабақтан есептеледі: Ұнады ÷ (Ұнады + Орташа + Ұнамады).
Сауалнамасы жоқ сабақтар есепте бөлек көрсетіледі. Жазылған пікірлер қайта импортталғанда сақталып қалады.

## Ай ауысқанда

Мұғалімдердің пәні мен потогы ай сайын өзгеруі мүмкін:
- «Айлар мен апталар» → **+ Ай қосу**. Өткен айдағы «кім қайда береді» тізімі көшіріледі. Өзгергенін «Кім қайда береді» бөлімінде түзетесіз.
- Немесе жаңа айдың бірінші аптасын бірден импорттаңыз. Ай мен апта өзі жасалады, жаңа мұғалім мен поток та қосылады.
  Жаңа мұғалімнің атын («Дәулет ағай» сияқты) және фотосын «Мұғалімдер» бөлімінде тексеріңіз.

Өткен айлардың нәтижелері өзгермейді.

## Пайдалы мәліметтер

- **Құпиясөзді ауыстыру:** **Settings → Environment Variables** → Key: `ADMIN_PASSWORD`, Value: жаңа құпиясөз → **Save** → Redeploy. Сонда тек жаңа құпиясөз жұмыс істейді, бұрын кірген құрылғылардың бәрі шығып қалады. Құпиясөз чатта жазылғандықтан, оны кейін ауыстырып қойған дұрыс.
- **Кіру ұзақтығы:** әкімші бір құрылғыдан кірсе, 30 күн бойы қайта сұралмайды. «Шығу» батырмасы кіруді бірден тоқтатады.
- **Екі адам бір уақытта өзгертсе:** бірінші сақталғаны өтеді. Екіншісіне «Сайттың жаңа нұсқасы бар» деген хабар шығады — жаңа нұсқаны ашып, өзгерісті қайта енгізеді. Деректер ешқашан үнсіз өшпейді.
- **Резерв көшірмелер:** әр сақтаудың көшірмесі Blob дүкеніндегі `data/history/` қалтасында тұрады (соңғы 40). Қате өзгерісті қайтару керек болса, керек көшірме сонда.
- **Іздеу жүйелері:** сайт Google-да көрсетілмейді (`noindex`).
- **Бастапқы деректер:** `seed/data.json` — claude.ai нұсқасындағы деректер (2026 ж. 2 қазан, 3-АЙ 4-АПТА, Junior математикамен). Бірінші сақтаудан кейін деректер Blob-та тұрады.
  claude.ai нұсқасында одан кейін қосылған апталарды мұнда сол аптаны импорттау арқылы қосасыз.

## SapaLine-ды толық автоматты түрде алу туралы

Сайттың өзі SapaLine-ға кіріп, сандарды алуы үшін SapaLine жағынан ресми қол жеткізу керек:
тек оқуға арналған аккаунт және API кілті. Оны SapaLine иесі ғана бере алады. Сондай рұқсат болса, сайтқа бір серверлік функция қосылады.
Әзірге сандар бетбелгі арқылы (апта сайын шамамен 1 минут) немесе Claude-тың апта сайынғы тапсырмасы арқылы алынады.

## Компьютерде іске қосу (міндетті емес)

Node.js 20 немесе одан жаңа нұсқасы керек.

```bash
npm install
cp .env.example .env.local      # қаласаңыз, басқа ADMIN_PASSWORD жазыңыз
npm run dev                     # http://localhost:3000   әкімші: http://localhost:3000/admin
npm test                        # API тексерісі
```

Компьютерде деректер `.data/` қалтасында сақталады.

## Файлдар

| Қалта | Не бар |
|---|---|
| `src/` | Беттің коды: `app.js`, `styles.css`, `shell.html`, `merge.js` (SapaLine сандарын біріктіру), `bookmarklet.js`, эмблемалар |
| `scripts/build.mjs` | `src/` ішінен `public/index.html` жасайды. Vercel әр деплойда өзі іске қосады |
| `api/` | Серверлік функциялар: `data` (деректер), `session` (кіру/шығу), `photo` (фото) |
| `lib/` | Сақтау (Vercel Blob), кіру, тексеру |
| `public/` | Бет, қаріптер, бастапқы фотолар |
| `seed/data.json` | Бастапқы деректер |
| `test/` | `npm test` тексерістері |
